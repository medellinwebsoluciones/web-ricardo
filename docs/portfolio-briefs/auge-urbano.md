# Auge Urbano — Real Estate platform

## Negocio
Sitio Flask para venta de propiedad raíz: captación de compradores y propietarios, admin de leads, SQLite local.

## Arquitectura
- Flask + templates
- SQLite leads
- Admin autenticado
- Assets/static

## Decisiones
1. Flask monolito inicial — time-to-market.
2. Leads en SQLite local — simplicidad operativa en fase temprana.
3. Flujos separados comprador/propietario — dos embudos.

## Outcomes
- Plataforma E2E de captación
- Admin de leads
- Base para automatización (agente inmobiliario)

## Hiring fit
Full-stack product build en vertical inmobiliario.
